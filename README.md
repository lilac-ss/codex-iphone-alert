# codex-iphone-alert

Codexの完了・承認要求をiPhoneへ繰り返し通知する、個人用のMac補助ツールです。

## 現在の状態

専用フォルダと独立Gitリポジトリを作成し、計画書・開発ルールを保存した段階です。
通知ツール、PWA、自動テスト、配信設定は、実装タスクでこれから作成します。
この段階ではCodexの通知設定やMacの起動項目を変更していません。

## 構成と動作

MacでCodexのイベントを検知し、Apple Web PushでiPhoneのホーム画面に追加したWebアプリへ通知します。
WebアプリはGitHub Pagesで配信します。
発生時に通知し、その後は1分ごと、最大30分まで再通知します。
ロックされていないMacでCodexを前面にすると、以後の送信を停止します。

iPhoneの通知は集中モード、消音、通知設定に従います。
常時鳴り続けるアラームや、集中モードを無視する通知を保証するものではありません。

## 秘密情報

VAPID秘密鍵と端末登録情報はMac内のリポジトリ外に保持します。
GitHub Pagesには静的な公開ファイルだけを配信します。
実データ、通知購読情報、秘密鍵、個人のCodex設定はコミットしません。
